The Abelii application infrastructure is an [OpenSource](https://opensource.com/) ( [MPL2](http://mozilla.org/MPL/2.0/) ) framework written in the [Abelii](https://gitlab.com/abelii/abelii) programming language which enables the authoring of hybrid applications (in Abelii) which target a wide range of environments - Linux, Windows, or Mac applications, Andriod and IOS mobile applications, and a hosted application as a website (see [abeliiApp](https://gitlab.com/abelii/abeliiapp) ).  Includes user interface infrastructure and database support, web service / http(s) client support, as well as cross platform support for file and process management (courtesy of Abelii).
