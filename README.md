The Abelii application infrastructure is aframework written in the [Abelii](https://gitlab.com/abelii/abelii) programming language licensed under the [MIT](https://opensource.org/licenses/MIT) open source license which enables the authoring of hybrid applications (in Abelii) which target a wide range of environments - Linux, Windows, or Mac applications, Android and IOS mobile applications, and a hosted application as a website.  Includes web user interface infrastructure and database support, web service / http(s) client support, as well as cross platform support for file and process management (courtesy of Abelii).
